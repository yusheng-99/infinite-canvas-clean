# 待测试

- 生图历史图片保护：删除“我的素材”、画布节点或项目触发本地缓存清理时，生图工作台历史记录引用的图片应继续正常显示。

- 画布提示词放大编辑：节点提示词输入框右上角新增放大按钮；弹窗内支持长提示词和 @ 资源引用，修改内容会实时同步回节点。

- 参考素材拖入：生图工作台可将图片直接拖入参考图区域；视频创作台可将图片、视频和音频拖入对应区域，原有格式、数量和大小限制继续生效。

- 本地存储查看：“配置与用户偏好”新增“本地存储”页，可查看应用数据、站点总占用、浏览器额度及各类 IndexedDB 内容明细。

- Freestylefly 提示词源：提示词广场和提示词选择器新增“Freestylefly GPT Image 2”，支持其数组格式数据、示例图、参考图、标签和作者信息。

- 画布组节点：底部工具栏新增"组"按钮；拖动节点到组上会高亮预览，松开后入组，随组整体移动；拖出组边界自动脱离；组节点无连接点、不参与连线，复制/粘贴不含组节点本身。

- @ 引用芯片输入：生成节点提示词输入框中输入 @ 可引用画布上的图片等资源，引用显示为带缩略图的芯片，可整体删除；发送时自动转换为资源引用。

- 生图透明背景：图片设置面板新增"透明背景"开关，开启后生成与图生图编辑请求会携带 background 参数（含自定义脚本模式）；重试也会保留该设置。

- 导出当前画布：画布左上角菜单新增"导出当前画布"，将当前画布结构与引用的本地媒体打包为 zip 下载。

- 保留提示词输入：生成节点点击生成后，提示词输入框内容不再被清空，可直接微调后再次生成。

- 页面切换动画：切换页面时旧内容淡出、新内容淡入上移（`AnimatePresence mode="wait"`），已去掉 `filter: blur` 动画（避免逐帧重算导致卡顿），仅保留 opacity + 微位移并加 `will-change`，整体时长缩短更丝滑；首页/画布全屏页用纯淡入淡出。需检查连续快速点击不同导航是否有闪烁或残留、低配设备是否流畅。

- 内容加载丝滑优化：新增全局 `.content-fade-in` 工具类（挂载时淡入上移），应用到 gallery / assets 网格与 image / video 历史列表容器，掩盖 localforage 异步水合完成时的内容硬弹出；密集图片（gallery 网格、assets 封面、image 历史缩略图）统一加 `decoding="async"` 让解码离开主线程。需检查各页首次进入时内容是否平滑出现、大量图片时是否还卡顿抖动。

- 主题配色柔化：主色由亮蓝 `#2563eb`/`#60a5fa` 改为柔和靛蓝 `#4c63d2`/`#8ea3f2`，并同步 `globals.css`、`app-theme.ts`（antd token）、`canvas-theme.ts`（画布选中框/节点激活描边/工具栏高亮）。需检查按钮、链接、侧栏激活项、画布选中框、菜单/表格选中态在深浅主题下是否统一且不刺眼。

- 首页纯启动器模式：首页不再显示左侧导航栏，全屏展示中间入口卡片，右上角保留配置/主题/版本/GitHub 快捷操作；进入任意工作台后侧栏正常显示，画布项目页保持原全屏行为。

- 全局字体优化：标题从宋体衬线改为现代无衬线（与正文同族更高可读性），等宽字体栈补充中文回退，配置弹窗脚本编辑器改用全局等宽字体变量；需检查首页大标题、各页面标题和脚本编辑区在 Windows 深浅主题下的显示。

- 侧栏导航重排：改为「创作 / 资源」两组分区，带小型分组标题；导航文字加大到 15px 全不透明前景色，图标 18px，激活项改为主题色文字 + 浅主题色底，弱化原先又小又淡的观感。

- 整体页面布局：桌面端改为「侧栏悬浮于渐变底壳 + 内容圆角卡片工作区」结构，侧栏去掉边框分割线，当前导航项改为卡片高亮加左侧主题色指示条；画布项目页仍保持全屏无边框，移动端布局不变。

- 画廊模块：顶栏新增“画廊”；支持上传、从素材导入、瀑布流欣赏和大图预览；画布图片节点“入画廊”、生图结果“画廊”可一键收藏，数据本地保存。

- 顶栏导航居中：logo 左、导航居中、操作右；欢迎页入口卡片等高并对齐。

- 欢迎页：改为苹果风居中大标题 + 轻量 CTA + 无边框产品入口网格，深浅主题下视觉保持干净简约。

- 画布底部工具栏：存为节点组/删除按钮常驻显示，未选中节点时置灰不可点，选中后恢复正常颜色，工具栏长度不再随选中变化。
- 全局 UI 显示重构：统一 `canvasThemes` 与 `appTheme` 设计 Token，消除深浅模式色彩断层；升级 App 顶栏为半透明吸顶玻璃悬浮条。
- 画布项目大厅 UI：项目卡片新增智能媒体图片预览与 Hover 快捷操作；支持名称搜索、多维排序（最近更新/最早更新/名称/节点数）及网格与列表视图一键切换。
- 画布工具栏极简分层：瘦身底部 Dock 为圆角胶囊面板，将外观样式与布局整理收纳为 Popover 弹出浮层，保持画布空间干净开阔。
- 画布节点 UI 重构 (Phase 4)：5 类节点（文本、图片、视频、音频、配置）采用统一的高保真 Header 结构、类型图标与状态指示；缩放手柄与边框高亮更加精致细腻。
- 节点快捷悬浮条瘦身 (Phase 4)：默认仅展示大图/下载/素材/重试等极简高频按键，低频次要功能统一收纳至「⋯ 更多」Popover 中，大幅降低节点上方的视觉遮挡。
- 提示词广场：顶部导航进入后可切换 nanobanana、Prompt-Manager 或自定义 JSON 数据源，并支持刷新、搜索、分类、标签、最新、收藏、投稿者筛选、分页和受限图片揭示。
- 提示词详情：可查看多图、参考图、投稿备注和提示词变体，支持复制、收藏、保存为本地文字素材及前往原投稿页面。
- 提示词应用：生图工作台、视频创作台和画布生成节点均可打开提示词选择器；广场详情点击“使用此提示词”会带入生图工作台。
- 画布一键投稿：单选已有内容的图片节点后，快捷工具栏显示“一键投稿”；弹窗自动带入图片、标题、提示词和模型信息，可修改投稿人、标签、备注、图片或公网图片链接后提交审核。
- 一键投稿图床：Catbox 返回 `Invalid uploader` 时自动切换到 ImgBB 上传，再继续提交投稿。
- 画布提示词广场：右上角入口打开提示词浮窗，支持搜索、分类、标签、收藏和详情；使用提示词后在当前画布中心创建对应文本节点。
- 大图预览性能：画布内视频播放时打开生成图片大图，视频与系统界面应保持流畅；缩放、拖动和关闭预览仍正常。
- 生成图片固定栅格：横图、竖图和正在生成或失败的图片混排时，自动生成落位与“整理布局”均按生成中图片节点尺寸保留统一行列间距，不再按成图真实比例挤压或拆分列。
- 节点信息弹窗：图片生成过程中点击节点“信息”可正常打开信息与 JSON 页面，不再出现 `key is not defined` 页面崩溃。
- 自定义模型调用：在“配置与用户偏好 → 模型”中可为默认生图或视频模型编辑调用脚本；脚本按渠道和模型独立保存，支持参考图、生成参数及最长十分钟轮询，清空脚本后恢复原有接口。
- 画布快捷创建：双击空白区域后在点击位置显示节点类型菜单，选择后在该位置创建节点。
- 节点快捷工具栏：鼠标经过节点时不再弹出，仅单选节点后显示；取消选择后自动隐藏。
- 多列生成落位：同一生成配置已有两列或更多输出批次时，新结果会落到当前底部最空的列下方；第二列较短时接在第二列下面，各列等高时从第一列开始排列。
- 生成节点自动落位：生成配置节点连续创建图片批次、视频、音频或文本时，新结果会沿已有输出列寻找下一块无重叠空位并立即整齐显示，无需再次点击整理。
- 混合布局防重叠：自动整理按相近左侧坐标分列，每列由上到下排列，再按列宽横向紧凑放置；不同上下分组不再被高节点合并到同一位置。
- 混合布局对齐：自动整理后各列左侧对齐并从共同顶部开始排列，列内根据节点实际高度保持纵向间距。
- 混合布局间距：自动整理保留原有上下/左右结构，同时压缩行列之间的过大空白，右侧节点组会整齐靠近左侧分组且不重叠。
- 混合方向自动整理：同一连通结构同时包含上下和左右分支时，整理后保留原有空间关系，仅吸附网格并整理批量子图片，不再整体旋转或拉成横排。
- 自动整理方向：位于上下方向的连通节点按纵向排列，位于左右方向的连通节点按横向排列；不同连通分组独立判断并保留原有方向。
- 批量图片自动布局：多个大图批次整理后各自保留根节点与子节点分组，子图片保持双列排列，不与其他批次混合。
- 画布自动布局：底部“整理布局”支持整理选中节点或整个画布；连线节点按从左到右分层，孤立节点整齐排列，批量选择后可对齐或等距分布，并可撤销。
- 画布拖动吸附：拖动节点时吸附到 16px 网格，并显示节点边缘或中心对齐辅助线；按住 Alt 拖动可临时关闭吸附。
- 画布节点编辑框：左键点击或框选画布空白区域后立即关闭，不再残留显示。
- 画布操作：鼠标中键拖动平移画布；左键拖动画布空白区域框选节点，Shift + 左键框选可追加选择，左键仍可拖动节点。
- 节点组素材：多选画布节点后可存为节点组；从“我的素材”插入时按原相对位置恢复节点、内部连线、配置引用与本地媒体，并自动生成新 ID。
- 前端字体与主题：正文、Ant Design 控件和画布文字使用现代中文无衬线字体，页面标题保留宋体；深浅主题统一使用画布蓝作为强调色。
- 画布文字清晰度：画布静止以及图片生成过程中，节点内“生成中”等文字保持清晰。
- 画布节点对比度：浅色和深色画布中的文本、配置、空媒体等默认节点与画布背景保持清晰边界，平移缩放停止后恢复轻量阴影。
- 界面动态效果：加载圆圈、悬停与面板过渡正常显示；开启系统“减少动态效果”后，画布左上角菜单仍能正常显示且页面无异常滚动区域。
- 视频创作台缓存：启动应用、删除画布节点/项目或删除“我的素材”后，历史记录引用的视频、参考图、参考视频和参考音频仍可正常打开。
- 画布界面与性能：更新画布主题、节点、底部工具栏和缩放控件；视口交互改为直接更新 CSS 并延迟同步状态，缩放和平移时图片保持连续显示。
- 前端界面：首页改为以画布为主入口的节点式创作起点，顶部导航改为扁平下划线状态；图片与视频工作台在中等宽屏隐藏历史栏并固定生成按钮，素材卡减少重复内容和操作噪声，画布项目卡更紧凑；验证宽屏、移动端和深浅主题布局。

- 画布视频设置：打开自定义秒数弹窗后，点击弹窗内控件不会关闭节点设置浮层。
- 画布视频设置：自定义秒数弹窗显示在节点设置浮层之上，不再被遮挡。
