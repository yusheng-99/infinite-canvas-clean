# 待测试

- 画布操作：鼠标中键拖动平移画布；左键拖动画布空白区域框选节点，Shift + 左键框选可追加选择，左键仍可拖动节点。
- 节点组素材：多选画布节点后可存为节点组；从“我的素材”插入时按原相对位置恢复节点、内部连线、配置引用与本地媒体，并自动生成新 ID。
- 前端字体：普通页面、Ant Design 组件与画布节点文字统一显示为宋体。
- 画布文字清晰度：画布静止以及图片生成过程中，节点内“生成中”等文字保持清晰。
- 视频创作台缓存：启动应用、删除画布节点/项目或删除“我的素材”后，历史记录引用的视频、参考图、参考视频和参考音频仍可正常打开。
- 画布界面与性能：更新画布主题、节点、底部工具栏和缩放控件；视口交互改为直接更新 CSS 并延迟同步状态，缩放和平移时图片保持连续显示。
- 前端界面：首页、顶部导航、画布库、素材库、图片与视频工作台统一视觉样式，并优化宽屏和移动端布局。
- 视频生成：Ray3.14 支持清晰度、比例、秒数与负面提示词参数。
- 画布视频设置：打开自定义秒数弹窗后，点击弹窗内控件不会关闭节点设置浮层。
- 画布视频设置：自定义秒数弹窗显示在节点设置浮层之上，不再被遮挡。
- 画布生成：切换生成类型后，实际请求也会使用对应类型的模型，避免视频节点仍提交旧模型。
- 视频创作台：生成任务会立即写入记录；本地媒体清理会保留视频生成记录引用的视频文件。
- 视频生成：所有模型的最长等待时间统一为十分钟。
- 视频创作台：视频秒数增加自定义输入弹窗，不受预设秒数限制。
- 视频生成：适配 chatgpt2api 的 `firefly-veo31` 与 `firefly-veo31-fast` 同步生成接口及最多两张参考图。
- 本地同步：Gemini 生图支持比例与分辨率、视频生成兼容直返 URL、重试结果持久化、画布模型自动匹配、图片切图可拖拽分割线，并修复中文输入法 Enter 误触发。
- 画布生图：保留质量选择，新增独立的 1K、2K、4K 分辨率选择，再选择宽高比；新增 21:9 超宽比例。
- 个人精简：移除本地 Agent、MCP 服务、Codex App 插件、画布里的本机连接入口和右侧画布助手工具区域。
- 主页精简：进入主页后在画面中间展示功能入口浮窗，顶部不再重复显示入口组，移除原介绍、入口按钮和提示词展示区。
- 个人精简：移除内置提示词库模块，包括顶部入口、独立页面、弹窗选择器和 `/api/prompts`。
- 个人精简：移除应用内文档入口和文档 URL 配置，避免继续跳转到过期文档。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
- 架构迁移：前端从 Next.js 切换到 Vite + React Router，移除 Next API 路由，本地配置继续保存在浏览器，Docker 运行改为 nginx 静态托管。
- 我的素材：文字素材卡片封面区域固定高度，长文本只显示前几行，避免把素材列表撑高。
- 配置偏好：生图成功音效改为下拉选择，上传后的自定义音效会显示在列表中并可切换。
- 配置偏好：生图成功音效增加试听按钮，可播放当前选择的内置或自定义音效。
- 版本更新：弹窗拆分“本地精简版更新”和“原项目更新”，本地版本号不再和原项目版本号混排。
- 版本更新：本地精简版更新记录在日期右侧显示对应原项目版本号。
- 本地缓存：应用打开并完成画布、素材数据加载后，自动清理未被引用的图片和媒体缓存。
- 我的素材：文本素材详情页和画布素材选择详情页增加“编辑内容”按钮，可直接修改素材里的文字内容。
