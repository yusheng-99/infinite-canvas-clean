# 商务合作

如果你希望围绕无限画布做商业合作、私有化部署、二次开发或模型渠道接入，请先在 GitHub 仓库发起讨论。不要在公开 Issue 中提交 API Key、真实用户数据或其他敏感信息。

## 适合沟通的方向

- 私有化部署、内网部署和团队版落地。
- 定制画布节点、生成流程、素材管理或后台能力。
- 接入自有 OpenAI 兼容接口或模型渠道。
- 围绕 AI 图片、视频、文本生成工作流做联合方案。
- 商业授权、技术支持、交付咨询或联合方案评估。

## 建议提供的信息

- 你的业务场景和预期用户规模。
- 需要部署的环境、数据保存方式和安全要求。
- 需要接入的模型、渠道、支付或账号体系。
- 期望的交付范围、时间和预算区间。

## 联系方式

目前本仓库未提供独立的商务邮箱。涉及商业授权或私有化交付时，请在讨论中说明计划使用方式和预期交付范围。
